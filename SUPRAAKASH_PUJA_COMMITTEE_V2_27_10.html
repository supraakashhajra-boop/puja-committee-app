⚙ Settings & Cloud Backup

☁️ Cloud Database Backup

এই Backup সরাসরি Supabase Cloud Database-এর রসিদ, Cash Handover এবং Income & Expense রেকর্ড Export করবে। এটি পুরোনো Browser Local Storage Backup নয়।

Backup করার আগে ইন্টারনেট সংযোগ চালু রাখুন।

♻️ Restore Cloud Backup

শুধুমাত্র Admin Restore করতে পারবেন। Restore পুরোনো রেকর্ড মুছে ফেলবে না; একই Record থাকলে আপডেট করবে এবং নতুন Record যোগ করবে। Backup ফাইলটি নির্বাচন করার পর নিশ্চিতকরণ চাইবে।

📒 Daily Cashbook

☁️ Automatic Cloud Backup & History

Admin login-এর পরে এবং অ্যাপ খোলা থাকা অবস্থায় ২৪ ঘণ্টা অন্তর Cloud Snapshot তৈরি হবে। Browser বন্ধ থাকলে নির্ধারিত সময়ে background backup চলবে না। Snapshot একই Supabase project-এ রাখা হয়; আলাদা disaster-recovery storage নয়।

🛡️ Fraud & Error Protection

  • Duplicate receipt serial check by bill type.
  • Amount/date validation before saving receipts and cashbook entries.
  • Backup restore confirmation and audit entry.
  • Record changes remain traceable through the existing audit log.

Receipt deletion is not added; existing receipt correction workflow remains in place.
